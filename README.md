# MELB | Landing Page

<p align="center">
  <img src="https://github.com/user-attachments/assets/1df0a890-8585-4a42-9360-0fa933164af5" alt="Logo MELB" width="100%"/>

> Uma landing page simples e responsiva feita para divulgação da marca MELB — com links diretos para redes sociais, loja online e WhatsApp.

---

## 🔗 Acesse o Projeto

👉 https://encodify.com.br/melb/

---

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **Materialize CSS**
- **Bootstrap 5**
- **JavaScript**
- **jQuery**

---

## 💡 Funcionalidades

- ✅ Design totalmente responsivo.
- ✅ Links rápidos para Instagram, Shopee e WhatsApp.
- ✅ Modais com QR Code para facilitar o acesso via celular.
- ✅ Tooltip com descrições nos ícones.
- ✅ Compatível com dispositivos móveis e desktops.
